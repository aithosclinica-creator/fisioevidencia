# FisioEvidencia

Biblioteca de literatura científica para fisioterapeutas. Prototipo.

- Busca en Europe PMC (incluye MEDLINE/PubMed) y agrupa los resultados en guías de práctica clínica, revisiones sistemáticas y ensayos aleatorizados.
- Excluye publicaciones retractadas y muestra la conclusión literal de los autores con enlace al original.
- **No ofrece recomendaciones clínicas** y no acepta datos de pacientes: bloquea DNI, teléfonos, emails, fechas y nombres.

Web: https://aithosclinica-creator.github.io/fisioevidencia/
